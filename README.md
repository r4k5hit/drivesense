# DriveSense AI
### Where Driving Dynamics Meet Intelligent Performance

DriveSense AI is an intelligent driving analysis platform built for automotive enthusiasts who value precision performance and control.

Using machine learning and road and track inspired simulations it analyses acceleration braking cornering behaviour speed management and road geometry.

It transforms driving data into performance insights helping uncover driving patterns and understand vehicle dynamics across every turn straight and braking zone.

**Engineered with:** Python · Streamlit · Pandas · NumPy · Scikit-learn · Random Forest

**Drive smarter. Read the road. Understand the performance.**
